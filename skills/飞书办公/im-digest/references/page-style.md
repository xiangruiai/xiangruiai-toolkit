# 小时情报 Page 样式（不是飞书卡片）

这是 Cursor / Grok 的 Page 呈现约定。没有 Page 工具时可以跳过，只发飞书卡片和写日节点。

更新当天的 Page 时，只改内容，呈现保持这一套。不要把飞书卡片的 200 元素回退逻辑套到 Page 上。

## 共用规则

- 用 `grok/canvas` 的 `Table`，不要用 Rows 做这几块
- 表头灰底，表身白底，行间细线，单元格垂直居中；不要加竖线，不要加外框
- 不要截断正文，不要写 `br`，不要给表格套滚动条，不要用直角引号
- 五块都用 `Section`，不要额外加折叠
- 来源栏格式：微信或飞书 · 会话 · 时间，用 `Source` 做成浅灰小字；蓝色短链接跟在来源文字后面，多个链接用 · 分隔
- 会话名若带【】前缀，去掉方括号，写成 `前缀 · 其余`

## 各块栏目

- 要处理的：优先级、事项、来源 · 会话 · 时间、附带链接（四栏）
- 客户与商单：客户、项目、阶段、下一步、来源 · 会话 · 时间（五栏）
- 值得知道的：事情、来源（两栏，链接放在来源栏）
- 可写的选题：选题、来源（两栏）
- 今日已解决：事情、来源（两栏，不要单独加已解决状态标签）

## 必备辅助组件

从 `grok/canvas` 引入 `Page`、`Section`、`Table`、`useGrokTheme`，并保留 `links` 和 `Source`。来源单元格写成：

```tsx
<Source text="微信 · 会话名 · 11-16 20:03" ls={[["知识库：政策板块", "https://example.com"]]} />
```

没有链接时省略 `ls`。空列表必须写成 `rows={[]}`，不要写成带空元素的数组。

推荐流程：用 `scripts/mkpage.py` 从状态文件生成 TSX，和当前 Page 源码对比后只插入变化行，避免整页重写。同一链接可能同时出现在客户行和已解决里，增量修改时要挑唯一片段。
